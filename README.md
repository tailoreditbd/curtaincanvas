# Curtain Canvas

Static, responsive homepage for [curtaincanvas.store](https://curtaincanvas.store/), built with semantic HTML5, CSS3, Bootstrap 5 and vanilla JavaScript for GitHub Pages.

## Local preview

Open `index.html` directly, or serve this folder with any static web server.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Set **Source** to **Deploy from a branch**, select `main` and `/ (root)`.
4. Keep the included `CNAME` file and point the domain DNS to GitHub Pages.

## Before analytics launch

- Replace the commented Google Search Console verification placeholder in `index.html`.
- Add your Google Tag Manager container (or GA4 tag) where marked.
- Replace `YOUR_CLARITY_ID` in the commented Microsoft Clarity snippet and uncomment it.
- Replace the social preview image with a branded 1200 × 630 image when available.

Remote photographs are loaded from Unsplash and Pexels. For maximum control and performance, download approved final images into `assets/img/` and update their URLs before launch.
